Supported File Formats¶

Source

File Extension

Description

DICOM

*.dcm,*.ima,*.2

Dicom CT or RT image files uncompressed

MapCheck

*.txt

MapCheck text files

PTW

*.mcc

PTW 729 array files only at this stage

IBA

*.opg

IBA Matrix and StarTrack opg files

Image

*.bmp

Windows bitmap

*.tif,*.tiff

Tagged Image format files.

*.jpg,*.jpeg

Joint Photographic Expert Group files

HIS

*.his

Raw unstructured data

XiO

None

Elekta XiO dose plane export text file

iPlan

None

BrainLab iPlan dose plane text file

RAW

*.txt

Structured text file

As the 2D array files have all been reverse engineered there is absolutely no guarantee of BeamScheme operating correctly on them. If you have a file that is causing BeamScheme to crash or is giving strange results please raise an issue at https://github.com/alanphys/BeamSchemeV1/issues and attach the file.
