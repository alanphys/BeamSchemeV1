XIM¶

A Varian XIM file is a binary file consisting of image, histogram and property data. It uses a proprietry compression format based on HND. XIM files are generated by the Varian accelerator built in tests such as MPC and IsoCal, and in Developer Mode. Only the image data is displayed.
